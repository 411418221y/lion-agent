## Summary
Provides a complete step-by-step guide for registering for courses at Columbia University each semester.

## Common student scenarios
- First-time registration
- Unsure when registration opens
- Difficulty adding courses

---

## Step-by-step: How to register for courses

### Step 1 – Review course offerings
- Use Course Directory or Vergil to browse available classes
- Check prerequisites and restrictions

### Step 2 – Confirm registration appointment time
- Log into Student Services Online (SSOL)
- Check assigned registration window

### Step 3 – Add courses during registration period
- Select desired courses in registration system
- Submit enrollment

### Step 4 – Verify enrollment
- Confirm courses appear on schedule
- Check credit totals

### Step 5 – Adjust during add/drop period if needed
- Add or drop courses before deadlines

---

## If registration is blocked

Common reasons:
- Account holds  
- Missing prerequisites  
- Time conflicts  

**Recommended action**
- Resolve holds in SSOL  
- Request prerequisite approval  
- Adjust schedule
