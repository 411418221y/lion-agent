## Summary
This is the single starting point for any major question. When a user asks about a major, always use this index to find the official major page link.

## Step-by-step: How to answer ANY major question (fast, reliable)
1) Open the official majors index:
   https://bulletin.columbia.edu/general-studies/majors-concentrations/
2) Find the user’s major name in the list (e.g., "Computer Science", "Economics", "Psychology").
3) Click into the specific major page.
4) Use ONLY that major page to pull:
   - Required courses (core)
   - Tracks/concentrations (if any)
   - Notes/exceptions (transfer credit, overlaps, etc.)
5) Return to the user:
   - Major page link (always)
   - A checklist of what to do next (below)
   - If missing details: say "Not covered in provided docs" + suggest what to check on the major page

## Output pattern (what the assistant should produce)
- Major official link: (paste)
- Checklist: 5–10 steps
- "Gateway/foundational course" concept (if applicable) with a clear label: Example only, confirm on major page
- Prerequisite-checking steps + registration tips links

## Notes
- Do NOT guess requirements. Always link the official major page.
- If the user only says “I’m CS”, still send the major page link and then ask them what year/experience level (optional).
