## Summary
Explains how students get technical support for accounts, devices, and campus systems.

## Common issues
- Password resets
- Wi-Fi access problems
- System login failures
- Software access

## How to get help
1) Use online IT support portal
2) Contact IT help desk
3) Visit campus tech support centers

## Emergency tech issues
- Account lockouts
- System outages

## School-specific notes
- Some programs offer dedicated IT support.
