## Summary
Explains how students use the academic calendar to track registration, withdrawal, and graduation deadlines each semester.

## Common student scenarios
- Missing add/drop deadlines
- Unsure when exams or registration start
- Forgetting graduation application cutoffs

---

## Most important deadlines to monitor

### Registration periods
- Appointment windows
- Open registration dates

### Course changes
- Add/drop deadline  
- Withdrawal deadline  

### Academic milestones
- Midterms and finals  
- Graduation application deadlines  

---

## Step-by-step: How to stay on top of deadlines

1) Visit the official academic calendar each semester  
2) Identify:
   - Registration dates  
   - Course change deadlines  
   - Exam periods  

3) Add deadlines to personal calendar  
4) Set reminder alerts  

---

## Common mistakes to avoid
- Relying on memory  
- Ignoring calendar updates  
- Assuming deadlines are the same each semester
