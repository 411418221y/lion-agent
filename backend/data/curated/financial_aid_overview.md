## Summary
Provides an overview of financial aid types and the general application process for Columbia University students.

## Types of financial aid
- Need-based grants
- Scholarships
- Federal and private loans
- Work-study programs

## Basic application requirements
- FAFSA submission
- CSS Profile (for some students)
- Supporting financial documents

## Typical timeline
- Aid application deadlines before each academic year
- Award notifications prior to semester start
- Disbursement at beginning of term

## Maintaining eligibility
- Satisfactory academic progress
- Enrollment status requirements

## School-specific notes
- Aid availability varies by school and program.
- Some programs have separate scholarship processes.
